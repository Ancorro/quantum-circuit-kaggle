# quantum-circuit-kaggle

One person plus AI coding agents entering the Google Quantum AI
[Verifiable Quantum Circuit Compilation](https://www.kaggle.com/competitions/google-verifiable-quantum-circuit-compilation)
Kaggle competition (2026-10-22 to 2027-01-20).

Agents edit circuit generators; the official kickmix verifiers check every
candidate exactly; only verified improvements are kept. The dated log of the
work is in [LOG.md](LOG.md). The competition survey that led here is in
[notes/survey-2026-10-31.md](notes/survey-2026-10-31.md).

Competition data is not redistributed here (rules section 4b).
